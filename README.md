SISTEMA DE FERRORAMA 

Sistema web de Ferrorama usado para adiministrar sensores de un tren. Permite cadastrar sensor, editar, visualizar e excluir sensores utilizando php e MySQL.

FUNCIONALIDADES

1. Cadastrar Sensores.
2. Listar Sensores.
3. Editar Sensores.
4. Excluir Sensores.
5. Armazenar dados no MySQL.
6. Utilizar Prepare Statement para maior segurança.

TECNOLOGIAS E LINGUAGENS UTILIZADAS

1. PHP
2. MySQL
3. HTML
4. CSS
5. XAMPP
6. VS CODE

COMO EXECUTAR

1. Inicie o Apache e o MySQL no XAMPP.
2. Coloque o projeto na pasta htdocs.
3. Crie o banco de dados utilizando o script SQL.
4. Acesse `http://localhost/nome-do-projeto/` pelo navegador.
